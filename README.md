# Sellaki Travaux — Finitions & Menuiserie d'Art

Site web moderne et vitrine professionnelle pour **Sellaki Travaux** — entreprise artisanale de travaux de finition de haute précision à Marrakech (menuiserie aluminium, menuiserie bois sur mesure, ferronnerie d'art et inox).

## Présentation

Sellaki Travaux accompagne particuliers, architectes et promoteurs immobiliers à Marrakech et ses environs dans leurs projets de construction neuve et de rénovation. L'entreprise est reconnue pour sa rigueur, son savoir-faire artisanal (*atqan*), la sélection de matériaux haut de gamme et le strict respect des délais de livraison.

## Fonctionnalités Principales

- **Vitrine des Métiers & Services** :
  - **Menuiserie Aluminium** : Châssis coulissants, baies vitrées à rupture de pont thermique, façades rideaux.
  - **Menuiserie Bois** : Portes intérieures et d'entrée, habillages muraux, dressings et cuisines sur mesure.
  - **Ferronnerie d'Art & Inox** : Garde-corps contemporains, portails motorisés, verrières d'atelier.
- **Galerie de Réalisations** : Portfolio interactif de chantiers livrés (villas à Marrakech, appartements de standing, commerces).
- **Processus de Réalisation** : Présentation claire des étapes de collaboration (prise de cotes, modélisation 3D, fabrication atelier, pose sur chantier).
- **Zones d'Intervention & FAQ** : Cartographie des secteurs d'intervention (Palmeraie, Hivernage, Guéliz, Route de l'Ourika, etc.) et réponses aux questions fréquentes.
- **Demande de Devis Rapide** : Formulaire d'estimation personnalisé et contact direct via WhatsApp / Téléphone.

## Technologies Utilisées

- **React 19**
- **TypeScript**
- **TanStack Start & TanStack Router** (Routage moderne et typé)
- **TanStack Query** (Gestion d'état et mise en cache)
- **Tailwind CSS v4** (Design moderne, responsive et fluide)
- **Radix UI** (Composants d'interface accessibles)
- **Lucide React** (Iconographie vectorielle)
- **Vite**

## Installation et Démarrage

### Prérequis

- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- [npm](https://www.npmjs.com/) ou [Bun](https://bun.sh/)

### Installation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/ahmedamarir-aseven/sellaki-travaux.git
   cd sellaki-travaux
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer le serveur de développement :
   ```bash
   npm run dev
   ```

4. Compiler pour la production :
   ```bash
   npm run build
   ```
